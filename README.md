Random Name Picker System
The archive contains the Windows executable program. No Python installation is required.
Usage Instructions
Extract the entire archive to a folder. Do not run the program directly inside the compressed archive.
Double‑click RandomNamePicker.exe to launch the application.
Import your name list to start random name selection. Click Reset Selection to begin a new round after all names have been picked.
File Description
RandomNamePicker.exe: Main application
names_data.json: Automatically generated at runtime to store name lists. Do not edit this file manually.
Notes
Windows may display a security warning. Click More info → Run anyway to proceed.
Name lists are stored in the same directory. When moving the executable, move the entire folder together. 
For Linux and macOS, please see [Cross‑Platform Guide](https://github.com/xksqx2023/Random-Name-Picker)
