# 随机点名系统
压缩包内包含Windows可执行程序，无需安装Python。

## 使用说明
1. 将压缩包全部解压到文件夹，**不要直接在压缩包内运行程序**
2. 双击 `随机点名系统.exe` 启动
3. 添加名单后即可随机点名，点完全部人员点击【重置点名】开启新一轮

## 文件说明
- `随机点名系统.exe`：主程序
- `names_data.json`：运行后自动生成，保存名单，请勿手动修改

## 注意
Windows可能提示安全警告，点「更多信息‑仍要运行」即可。名单保存在同目录，移动exe需要连带整个文件夹一起移动。
